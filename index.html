Directory Structure

For the scanner to function properly, all three binaries must remain in the same directory:

  • PLfinder.exe — Main interface and orchestrator
  • asnlookup.exe — Network range resolution via ASN / IPv4
  • reconhound.exe — Port and header scanning engine
