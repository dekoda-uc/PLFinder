# PLfinder

An example tool for scanning vulnerable Cesbo Astra lists to audit and secure them.

## Prerequisites

Before running the application, make sure you have the following binaries placed in the **same folder**:

- `asnlookup.exe`
- `reconhound.exe`

---

## Usage

To start the application:

```bash
.\PLfinder.exe
```
